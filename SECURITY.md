Atualmente, fornecemos atualizações de segurança para as seguintes versões ativas do **Academia-arcana-MCP**:

| Versão | Suportada          |
| ------ | ------------------ |
| 1.1.x  | :white_check_mark: |
| 1.0.x  | :x:                |

## Relatando uma Vulnerabilidade

A segurança do servidor MCP e da comunicação com o Foundry VTT é nossa prioridade.

Se você descobrir uma vulnerabilidade de segurança, por favor **NÃO abra uma Issue pública**.

Em vez disso, siga o procedimento abaixo:

1. Envie os detalhes da vulnerabilidade para os mantenedores do repositório.
2. Inclua:
   - Descrição detalhada da vulnerabilidade.
   - Passos para reproduzir o problema.
   - Versão do servidor MCP e do Foundry VTT utilizada.
   - Impacto potencial estimado.

Entraremos em contato em até 48 horas úteis para confirmar o recebimento e discutir os passos de correção.
